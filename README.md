# Montich Bot

Stage 9 adds a bounded learning mini-session.

## Included in this stage

- Mini-session with a fixed number of cards
- Session progress during learning
- Final session summary with results
- Text answer by default with a fallback button for unknown words

## Learning flow

1. Press `Учить сербский`.
2. The bot starts a mini-session of 10 cards.
3. Type the Russian translation as a normal message.
4. If the word is unknown, press `Я не знаю этого слова`.
5. The bot shows the translation, marks the word for repetition, and sends the next card.
6. After the last card, the bot shows a short session summary.
